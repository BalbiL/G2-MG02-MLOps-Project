This is the first version of the api (only the news table is available for now in supabase)

To locally start the API on a linux machine from the terminal, you need to:

1-Navigate to the api folder (where this file is)

2-If its the first time ever hosting the API locally, create a python virtual environment with: python3 -m venv <venv_name>

3-Activate the venv with: source <venv_name>/bin/activate

4-If its the first time ever hosting the API locally, install the dependencies with: pip install fastapi uvicorn supabase

5-Run the app with: uvicorn app:app --reload (--reload flag allows to update if changes are made)

The API should be running on port 8000 of localhost.

Documenation and a testing area for teh API are available at http://localhost:8000/docs
